# 中止時の払い戻し手続き（案）— 委員会でご決定ください

作成: 2026年9月19日（サイト担当）　対象: 第8回秋川流域花火大会（2026年11月14日・土）
目的: 中止になった場合に「どこに・いつまでに・どうやって申し込むか」を来場者がサイトで確認できるようにする。
現在のサイトの記載: 「中止の場合のみ払い戻しになります。手続きの方法は決まり次第このページでお知らせします。購入時のメールは保管してください」（天候・開催情報ページ）

---

## 1. 販売サイトごとの払い戻しの流れ（一般的な仕組み・要確認）
チケットは5つの販売サイト＋ふるさと納税で販売しているため、払い戻しは**各販売サイトの仕組み**で行うのが通常です。主催者が直接返金するのは、通常ありません。

| 販売サイト | 一般的な払い戻し方法 | 主催者側で必要なこと（想定） | 確認 |
|---|---|---|---|
| アソビュー（ウラカタ） | 主催者が管理画面で「中止」処理をすると、購入者に自動で返金（クレジット決済の取り消し） | 中止処理の操作。締切の設定 | □ アソビュー担当に確認済み |
| チケットぴあ | ぴあが払い戻し期間を設定し、購入者が店頭またはWebで手続き | ぴあへの中止連絡と払い戻し期間の合意 | □ 確認済み |
| KKday | KKdayが購入者に返金 | KKdayへの中止連絡 | □ 確認済み |
| 楽天トラベル | 楽天が購入者に返金 | 楽天への中止連絡 | □ 確認済み |
| JRE MALL | JRE MALLの規約に従い返金 | JRE MALLへの中止連絡 | □ 確認済み |
| ふるさと納税（さとふる） | 寄付は原則返金なし。返礼品（チケット）の扱いはさとふる・自治体との取り決めによる | さとふる・あきる野市への確認 | □ 確認済み |
| 駐車券 | 観覧チケットと同じ扱いにするか | □ 同じ扱い ／ □ 別途判断 | |

## 2. 決めていただきたいこと
| 項目 | 案 | 決定 |
|---|---|---|
| 払い戻しの対象 | 中止の場合のみ（現在の記載どおり）。花火開始後の中止は対象外 | □ 採用 ／ □ 修正 |
| 花火だけ中止（ステージ・飲食は実施）の場合 | □ 全額払い戻し ／ □ 一部 ／ □ 対象外 | |
| 受付期間の目安 | 中止決定日から **2週間**（販売サイトの規定が優先） | □ 採用 ／ □ ＿週間 |
| 手数料 | 販売サイトの規定による（購入者負担の手数料が生じる場合あり） | □ 採用 |
| 問い合わせ窓口 | 販売サイトのサポート窓口を第一の窓口にし、主催者へはWebフォーム | □ 採用 |
| 各社への連絡担当 | チケット担当（＿＿） | □ 決定 |

## 3. サイトに載せる文面（案）
決定後、「天候・開催情報」ページの「払い戻しについて」を次のように差し替えます。

> **払い戻しについて（中止の場合のみ）**
> 荒天などで大会が中止になった場合、チケット代金は**ご購入いただいた販売サイト**を通じて払い戻します。主催者が直接返金することはありません。
> - アソビュー：自動で返金されます（手続き不要。決済方法により返金までの日数が異なります）
> - チケットぴあ／KKday／楽天トラベル／JRE MALL：各サイトからのご案内に沿ってお手続きください（受付期間：中止決定から＿＿週間）
> - ふるさと納税（さとふる）：＿＿＿
> ※花火開始後の中止、交通機関の遅延・渋滞でご来場できなかった場合は、払い戻しの対象になりません。
> ※購入時の確認メールは、払い戻しが終わるまで保管してください。

## 4. 事前にできる準備（サイト担当）
- 上記の文面を、空欄だけ埋めれば公開できる状態で用意しておきます
- 中止が決まった際は、「天候・開催情報」ページとトップページの帯を同時に更新します（更新は5分程度）
