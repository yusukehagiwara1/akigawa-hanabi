## ① このページの目的

計画表の「ねらい」に対応します。

1. **当日の判断と準備の情報を一箇所にまとめる**
   「雨でもやるのか」「中止のときにお金は戻るのか」「何を着ていけばよいか」は、今は「よくある質問」の中に分かれて載っています。来場を考えている方が迷わないよう、天候にかかわる情報をこのページにまとめます。
2. **電話でのお問い合わせを減らす**
   大会当日、いちばん多いと考えられる「今日はやりますか？」という問い合わせに、電話ではなくこのページで答えられるようにします。ページの先頭に「開催状況」の欄を置き、更新した日時を必ず書くことで、「この情報は最新か」が一目で分かるようにしています。
3. **大会週は、トップページの最上部から案内する**
   サイトを開いた人が最初に開催状況に気づけるよう、トップページの一番上に「開催情報の帯」を出します（②の後半と「⑦ 当日の更新手順書」を参照）。

読む人は「来場を検討している一般の方」と「当日、会場に向かう途中の方」で、約85%がスマートフォンです。スマートフォンで縦にたどるだけで分かる作りにしています。

### トップページ最上部の「開催情報の帯」（2通り用意）

**A. SWELLの「お知らせバー」機能を使う（おすすめ）**

サイトのデザイン（SWELL）に、全ページの上部に1行のお知らせを出す機能があります。文字を入れるだけで出せて、色も選べるので、当日の更新が簡単です。

- 設定の場所: WordPress管理画面 →「外観」→「カスタマイズ」→「サイト全体設定」→「お知らせバー」
- 設定する項目（項目名はSWELLの版によって少し異なることがあります。画面の項目に合わせてください）
  1. お知らせバーを表示するか → 「表示する」（表示範囲を選べる場合は「全ページ」。当日はどのページを開いた人にも見えるようにするため）
  2. 表示する文章 → 下の文言案から選び、日時を入れる
  3. リンク先のアドレス → `https://machizukuri-con.or.jp/kaisai-joho/#akg-wx-status`（開催情報ページの「開催状況」の欄へ直接移動します）
  4. 背景色・文字色 → 開催＝緑系、判断中＝橙系、中止＝赤系（見やすい濃い背景に白文字がおすすめ）
  5. 「公開」ボタンで反映
- 出す期間の目安: 11月7日（土）〜11月15日（日）。終了後は「表示しない」に戻します（③で確認）。
- ※ 実際の画面で項目名と表示位置を確認し、公開前に画面写真つきの手順に差し替えます（担当: 萩原、要動作確認）。

文言案（スマートフォンで1〜2行に収まるよう、40字程度までにしています）:

| 場面 | お知らせバーの文章（案） |
|---|---|
| 大会週（通常時） | 【開催情報】11/14(土)の花火大会は予定どおり開催の見込みです。雨のとき・服装の目安はこちら |
| 当日・開催 | 【本日開催】11/14(土)の秋川流域花火大会は予定どおり開催します（○時更新） |
| 判断中 | 【開催情報】天候により開催を判断中です。○時までにこのサイトと公式Instagramで発表します（○時更新） |
| 中止 | 【中止のお知らせ】11/14(土)の秋川流域花火大会は中止となりました。払い戻しについてはこちら（○時更新） |
| 終了後 | 【御礼】第8回秋川流域花火大会は終了しました。ご来場ありがとうございました |

**B. 代替: `banner.html`（トップページ本文の一番上に置く帯）**

お知らせバーが使えない場合や、トップページの本文の中にも同じ帯を置きたい場合に使います。

- トップページの本文の一番上に「カスタムHTML」ブロックとして貼ります。
- 通常時は**非表示**にしてあります（コードの中に `hidden` という単語が入っているため、画面には出ません）。表示するときは、この `hidden` の1語を消して「更新」します。戻すときは `hidden` を書き戻します。
- 文章は `<span class="akg-wx-bar__msg">…</span>` の中、更新日時は `<span class="akg-wx-bar__meta">…</span>` の中を書き換えます。
- 色は、`akg-wx-bar--open`（緑・開催）の部分を `akg-wx-bar--pending`（橙・判断中）／`akg-wx-bar--cancel`（赤・中止）／`akg-wx-bar--end`（灰・終了）に書き換えると変わります。
- リンク先は開催情報ページ（`/kaisai-joho/#akg-wx-status`）です。ページのアドレスを変える場合は、ここも合わせて直します。

## ④ 公開までの流れ

1. **下書きの作成**（担当: 萩原）
   - WordPressに固定ページとして下書き保存します。見た目の設定は「よくある質問」ページと同じ（1カラム・サイドバーなし）にします。
   - タイトル「天候・開催情報（雨のとき・中止のとき・服装の目安）」、アドレス「kaisai-joho」、検索結果に出る説明文（`meta.json` の excerpt）を設定します。
2. **動作確認**（担当: 萩原）
   - スマートフォン実機で、目次ボタン・開催状況の欄の色・ボタンの押しやすさを確認します。
   - 開催状況の欄の色の切り替え（⑦の手順）を、下書きの状態で一度試します。
   - SWELLの「お知らせバー」を試しに表示し、文章の長さと色を確認したうえで非表示に戻します。
3. **委員会の確認**（③の表の項目）
   - いただいた内容で黄色い確認枠を差し替え、不要な枠は削除します。
   - 更新担当者に、⑦の手順で「開催状況の欄を書き換えて更新する」練習をしていただきます（10月中）。
4. **公開**（10月24日(土)目標）と、リンクの設置
   - グローバルナビ（上部メニュー）: 「よくある質問」の隣に「天候・開催情報」を追加（項目が多ければ「よくある質問」の子項目）。フッターメニューにも追加。
   - チケット情報ページ: 「諸注意」の近くに「雨のとき・中止のときの決まりはこちら」のリンクを1つ追加。
   - 交通アクセス・よくある質問: 「当日の天候について」の付近に、このページへのリンクを1つ追加。
   - 「初めて来る人へ」（施策⑧、10月17日公開目標）: 「行く前」の服装・持ち物の項目からリンク。
   - SNS（Instagram・X）: 公開時に「雨のとき・服装の目安をまとめました」と投稿。メールマガジンを配信する場合は、その本文からもリンクします。
5. **大会週（11月7日〜）**
   - トップページ最上部にお知らせバー（または banner.html の帯）を表示します。
   - 前日・当日の更新は⑦の手順書のとおりに行います。
6. **大会後**
   - 開催状況の欄を「終了しました。ご来場ありがとうございました」（灰色）にし、お知らせバーを非表示に戻します。ページ自体は来年に向けて残します（第9回の案内に書き換えて再利用できます）。

### 7-3. 開催情報ページの「開催状況」の欄を書き換える手順

1. WordPressにログイン → 左のメニュー「固定ページ」→「天候・開催情報」を開く。
2. 緑色の枠の中の大きな文字（例「予定どおり開催します」）をクリックし、文章を書き換える（下の「文言テンプレート」から貼り付け）。
3. その下の「最終更新：」の日時を、今の日時に書き換える（例「2026年11月14日(土) 8:00」。必ず書き換えます）。
4. 一番下の説明文（開催日・会場・時間の一文）を、必要に応じて書き換える。
5. **枠の色を変える**: 中止・判断中に変えるときは、枠の色も必ず変えます（緑のまま「中止」と書くと誤解のもとです）。枠の外側（緑の線）をクリックして枠全体を選び、右側の設定の一番下「高度な設定」を開き、「追加CSSクラス」の欄の文字を次のどれかに書き換えます。操作に迷ったら、文章だけ先に更新して萩原に連絡してください。
   - 予定どおり開催（緑）: `akg-wx-status akg-wx-status--open`
   - 天候により判断中（橙）: `akg-wx-status akg-wx-status--pending`
   - 中止（赤）: `akg-wx-status akg-wx-status--cancel`
   - 終了（灰）: `akg-wx-status akg-wx-status--end`
6. 右上の「更新」ボタンを押す。
7. 確認する人が、スマートフォンで公開ページを開き直して（画面を下に引っ張って再読み込み）、文言・日時・色を確認 → 更新する人に「確認OK」。
8. 表示が変わらないときは、しばらく待ってからもう一度読み込む（サーバー側の一時保存の仕組みで、数分かかることがあります）。それでも変わらない場合は萩原へ連絡。

### 7-4. トップページのお知らせバーを書き換える手順

1. WordPressにログイン → 左のメニュー「外観」→「カスタマイズ」→「サイト全体設定」→「お知らせバー」。
2. 「表示する」になっていることを確認し、文章を書き換える（②の文言案の表から選び、「○時更新」を今の時刻に）。
3. 必要に応じて背景色を変える（開催＝緑系、判断中＝橙系、中止＝赤系）。
4. 上の「公開」ボタンを押す。
5. スマートフォンでトップページを開き直して確認。
（banner.html の帯を使っている場合は、トップページの本文の一番上の「カスタムHTML」ブロックを開き、②-Bのとおり文章・日時・色を書き換えて「更新」します。）
