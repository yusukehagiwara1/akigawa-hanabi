## 3. 公開までの流れ

1. **下書きの作成**（担当: 萩原 — 済み）
   WordPressに下書きとして保存し、確認用のアドレスをお送りします。
2. **内容確認**（委員会・1〜2日）
   上の表の回答をいただき、黄色い枠を差し替えるか削除します。期限までに届かないものは、枠を外して公開し、届き次第あとから追加します（⑪のメッセージ・写真、②③⑧のステージ・帰りの交通など）。
3. **公開**（担当: 萩原が実施）
   目標日の順に公開します: 9月19日（土）⑫⑬ → 9月26日（土）⑪ → 10月3日（土）②③ → 10月10日（土）⑤ → 10月17日（土）⑧ → 10月24日（土）⑩。
   公開の順番に決まりがあるものは次のとおりです。
   - ⑫（音楽紹介）を公開したら、⑪と③の「第8回の楽曲は、お知らせでご紹介します」のリンク先を、その記事に直します。
