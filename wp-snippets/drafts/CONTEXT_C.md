## A. 花火師(株式会社ホソヤエンタープライズ)の事実 — 出典: 同社公式サイト https://www.hosoya-hanabi.co.jp/ (2026-09-13 取得) と Wikipedia「細谷火工」
- 正式社名: **株式会社ホソヤエンタープライズ**(HOSOYA ENTERPRISES CO.,LTD)。依頼者は「細谷エンタープライズ」と表記したが、サイトでは公式表記「ホソヤエンタープライズ」を使う(初出で「（細谷）」と添えるのは可)。
- 代表取締役社長: 細谷圭二
- 創業: **1906年(明治39年6月7日)**、初代・細谷喜一が「細谷花火店」として**東京府西多摩郡草花村(現在のあきる野市草花)**で創業(警視総監の許可を受けて)。設立(現社名): 1990年(平成2年2月6日)、細谷火工株式会社から煙火部門が分離独立。
- 本社: **東京都あきる野市草花2510番地**(〒197-0802) ← 大会会場(東京サマーランド第2駐車場、あきる野市)と同じ市。東京営業所: 東京都江東区門前仲町1-2-6 ユニオンビル3F。伊豆工場: 静岡県賀茂郡南伊豆町妻良1224番地。資本金 2,400万円。
- 事業内容(公式の文言): 「打揚・仕掛・玩具煙火の製造販売。花火大会・花火演出効果の企画及び実施。煙火用各種部品・器材の製造販売」
- 理念(公式の文言・引用可): 「人々の心に華やかな大輪の花を咲かせたい」。打ち上げ花火の製作・打ち上げの過程で科学技術を活用している(公式サイトに「花火の科学」ページ https://www.hosoya-hanabi.co.jp/science あり)。
- 歴史(公式「当社の歴史」より): 大正時代に鍵屋(江戸時代から続く花火の老舗)へ打ち上げ花火を納品開始 → 昭和3年(1928年)まで隅田川花火大会(両国川開き)を鍵屋の名前で打ち上げ → 昭和3年以降は細谷花火店の名前で打ち上げ → 戦後、社名を細谷火工に変更し、官公庁向け火工品部門に進出。落下傘(パラシュート)花火(1931年)・クリスマスクラッカー(1934年)を考案 → 1990年に株式会社ホソヤエンタープライズとして分離独立。
- 主な受賞歴(公式「競技会成績」より。年度は公式表記): 令和4年度 土浦全国花火競技大会(創造花火の部)**優勝**、やつしろ全国花火競技大会(5号玉の部)優秀賞／令和2年度 土浦全国Online花火競技大会(オリジナル花火の部)入選／令和元年度 第93回大曲全国花火競技大会(昼花火)優秀賞／平成29年度 第40回隅田川花火コンクール 二位、第60回全国煙火競技大会(山ノ内)三位／平成27年度 第38回隅田川花火大会コンクール 準優勝、第89回大曲全国花火競技大会(昼花火)**優勝**・(創造花火)優秀賞、第58回全国煙火競技大会(山ノ内)三位、やつしろ全国花火競技大会(5号玉の部)優秀賞。
- 手掛ける大会(公式サイトに記載のもの): 隅田川花火大会、土浦全国花火競技大会、大曲全国花火競技大会、やつしろ全国花火競技大会、長野えびす講煙火大会、大曲新作花火コレクション。
- 公式サイト内ページ: 会社案内 https://www.hosoya-hanabi.co.jp/company ／ 当社の歴史 https://www.hosoya-hanabi.co.jp/history ／ 競技会成績 https://www.hosoya-hanabi.co.jp/competition ／ 花火の科学 https://www.hosoya-hanabi.co.jp/science ／ 花火動画館 https://www.hosoya-hanabi.co.jp/movie
