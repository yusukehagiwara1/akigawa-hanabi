# 花火売上集計スプレッドシート「在庫」シート

スプレッドシート: [花火売上集計](https://docs.google.com/spreadsheets/d/1456s7-6nzhmIskjOuwVhIiSQ6TOk7KuQKYWkO51YdWw/edit)（シート名「在庫」）

配分（各販売サイトへの割当）から「集計」シートの販売数を引いて、残りと記号（〇／△／✕）を出しています。
すべて**数式**なので、集計シートを更新すれば在庫シートも自動で変わります。GAS・トリガーは使っていません。

## 構成

- ① 席種ごと（6〜13行）… 在庫数・販売数・残り・残率・表示（空席あり／残りわずか／完売）
- ② 販売サイト別（16〜58行）… 席種 × 6サイトで 配分・販売数・残り・残率・記号
- H列「集計シートでの表記」… 集計シートはサイト名が「ぴあ」「JR MALL」「ふるさと納税」なので、照合用に持っています

## 記号の判定

| 記号 | 条件 |
|---|---|
| ✕ | そのサイトの残りが 0 以下 |
| △ | そのサイトの残率が 25% 以下、またはその席種全体の残率が 25% 以下 |
| 〇 | 上記以外 |
| ― | 配分が 0（そのサイトでは取り扱いなし）または空欄（さとふる＝按分対象外） |

サイトのチケットページの 〇＝緑／△＝黄／✕＝赤 と同じ基準です。

## 配分を変えるとき

②の「配分」列（C列）を直すだけです。①は②を合計しているので自動で追随します。
配分の出どころは「[花火座席情報・座席按分](https://docs.google.com/spreadsheets/d/1OZRzFaeRyLd0lbebkrI5AD3wPwuGuuxlI8se-dvSx6M/edit)」の座席数按分シート。

## シートを作り直すとき

`zaiko.tsv` の中身をコピーして、在庫シートの A1 に貼り付けてください（数式ごと入ります）。
