# 花火売上集計スプレッドシート「在庫」シート

[花火売上集計](https://docs.google.com/spreadsheets/d/1456s7-6nzhmIskjOuwVhIiSQ6TOk7KuQKYWkO51YdWw/edit) の「在庫」シート。

配分（各販売サイトへの割当）から「集計」シートの販売数を引いて残りを出しています。
すべて**数式**なので、集計シートを更新すれば自動で変わります。GAS・トリガーは使っていません。

## 構成

- ① 席種ごと（5〜12行）… 席種／在庫／販売／残り／残率／状況
- ② 販売サイト別（15〜57行）… 席種 × 6サイトで 配分／販売／残り／残率／記号

集計シートはサイト名が「ぴあ」「JR MALL」「ふるさと納税」なので、数式の中で SWITCH で読み替えています。

## 記号

| 記号 | 条件 |
|---|---|
| 〇 | 在庫あり |
| △ | そのサイトの残りが25%以下、またはその席種全体の残りが25%以下 |
| ✕ | そのサイトの残りが0 |
| ― | 配分0（取扱なし）または空欄（さとふる＝按分対象外） |

サイトのチケットページの 〇＝緑／△＝黄／✕＝赤 と同じ基準です。

## 配分を変えるとき

②の「配分」列（C列）を直すだけ。①は②を合計しているので自動で追随します。
配分の出どころは「[花火座席情報・座席按分](https://docs.google.com/spreadsheets/d/1OZRzFaeRyLd0lbebkrI5AD3wPwuGuuxlI8se-dvSx6M/edit)」の座席数按分シート。

## シートを作り直すとき

`gen_zaiko.py` を実行すると `zaiko.tsv`（数式のみ）と `zaiko.html`（書式つき）が出ます。
`zaiko.html` をクリップボードに text/html で入れて在庫シートの A1 に貼り付けると、罫線・見出し色ごと入ります。
